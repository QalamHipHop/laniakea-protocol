# Guides

How-to guides, tutorials, and cookbook recipes for working with the
LaniakeA Protocol.

Start with:

- `../DEVELOPER_GUIDE.md` — local dev, conventions, adding endpoints
- `../USER_MANUAL.md` — using the API and dashboards
- `../CONTRIBUTING.md` — contributing to the project
- `../SECURITY.md` — reporting vulnerabilities

Add new guides as `*.md` files in this directory and link them from
`../DEVELOPER_GUIDE.md`.
