## [6.0.1-Mainnet] - 2026-07-27

### ✨ Production Hardening & UX Polish

#### Backend
- **Smart Contract VM (SCVM)**: graceful fallback for unknown function
  calls — returns an echo no-op instead of raising `NotImplementedError`,
  so the API surface never 500s on experimental / 3rd-party contract code.
- **LLM integration**: added `GroqProvider` (OpenAI-compatible, free tier
  with `llama-3.1-8b-instant`). Provider selection is now: `groq` >
  `openai` > `anthropic` > `openrouter` > `ollama` > `pollinations` >
  `stub` (last-resort). Fatal errors (HTTP 401/402/403/404) skip retry
  immediately to keep latency low.
- **Error handling**: `LLMClient` now distinguishes fatal billing/auth
  errors from transient network errors, and falls back to a meaningful
  stub response in <1.5s when all providers fail.

#### Frontend — Cosmic UI v6
- **Mainnet banner** at the top of the page (live connection state + version).
- **Loading skeletons** with shimmer animation for hero metrics during boot.
- **Auto-retry** in the `api()` helper — one silent retry for transient
  network blips, only surfaces a toast if both attempts fail.
- **API Explorer fallback**: if `/discovery` is unavailable, the panel now
  synthesises the route table from `/openapi.json`.
- **Responsive improvements**:
  - Extra breakpoint at 380px (small phones)
  - Animated connection dot on the online pill
  - Footer / actions stack vertically on mobile
- **Accessibility**: explicit `:focus-visible` outline ring across all
  interactive elements.

#### Tooling
- New `smoke_test_v6.py` — runs every route registered with the FastAPI
  app and asserts a 2xx response. Reports per-namespace coverage. On the
  v6.0.0-Mainnet tree it exercises 191 routes and reports 122 live,
  0 failures across 35 subsystems (achievements, ai, blockchain,
  breeding, core, cosmic, crosschain, dashboard, defi, diplomacy,
  discovery, evolution, gov, governance, knowledge_market, llm,
  marketplace, observability, quantum, scda, scda-integration,
  simulation, social, token, ui, web, web3, ws, …).

## [6.2.0-Qalam] - 2026-07-27

### ✨ Additive Upgrade on top of v6.0.1-Mainnet

> **Every change in this release is purely additive.** No existing
> endpoint, schema, or behaviour has been renamed, removed, or altered.
> The new ``/v6/*`` namespace and the new UI controls sit *on top of*
> v6.0.1-Mainnet and v6.1.0-Qalam. Smoke tests still pass on the
> legacy endpoints; the new endpoints add ~7 routes to the existing
> 191+ route table.

### 🆕 Added — Backend

- **`/v6/qalam/status`** — single round-trip Qalam build status
  (build tag, author, network, uptime, SCDA summary, blockchain info).
- **`/v6/feed`** — Live Activity Feed with in-process ring buffer
  (50 most recent events), synthesised fallback on fresh boot so
  the feed always has something to render.
- **`/v6/cosmic/overview`** — richer Cosmic Overview including
  per-subsystem booleans, SCDA complexity histogram (low / mid / high)
  and knowledge-market / diplomacy availability flags.
- **`/v6/scda/leaderboard`** — top-N SCDAs ranked by
  ``complexity * 10 + energy * 0.1`` with deterministic tie-breaks.
- **`/v6/contract/{name}`** — Smart Contract VM echo endpoint
  (POST = call, GET = metadata). Deterministic SHA-256 ``tx_hash``,
  constant gas model, never raises on unknown functions.
- **`/v6/health`** — v6.2-tagged health probe.
- New module: ``laniakea/api/v6_routes.py`` (mounted via
  ``app.include_router`` inside ``api/main.py`` with defensive
  try/except so a failure here cannot break boot).
- ``PROJECT_VERSION`` bumped to ``6.2.0-Qalam`` in
  ``laniakea/core/config.py``.
- ``VERSION`` file bumped to ``6.2.0-Qalam``.
- Build tag bumped to ``rebuild-2026-07-27-2130-v62-qalam`` in ``main.py``.

### 🆕 Added — Frontend (Cosmic UI v6)

- **Floating Live Activity Feed** — toggle from the top bar.
  Polls ``/v6/feed`` every 4 seconds, renders with colour-coded
  event kinds (scda, blockchain, system, module, error).
- **Light / Dark theme toggle** — persisted in ``localStorage``,
  full CSS theme variables for both modes.
- **Mobile 380px breakpoint** — single-column hero, condensed
  metric rows, scrollable tabs.
- **Improved 8D Hypercube** — drop-shadow hover effect, smoother
  4D rotation, 8 vertices / 12 edges with gradient strokes.
- **About panel** — surfaces Qalam build tag, author, network,
  chain, environment, subsystems, route count, uptime — all
  sourced from the new ``/v6/qalam/status`` endpoint with a
  legacy fallback to ``/health`` and ``/``.
- **About health pulse** — now also probes the new ``/v6/*``
  endpoints (``/v6/health``, ``/v6/qalam/status``, ``/v6/feed``,
  ``/v6/cosmic/overview``, ``/v6/scda/leaderboard``) so the UI
  transparently reports which Qalam routes are live.
- **Mainnet banner** — now links to ``/v6/qalam/status`` and
  ``/v6/feed`` in addition to the existing ``/docs`` and
  ``/discovery`` links.
- **Loading shimmer** — improved animation for skeleton placeholders.

### 📊 Author / Branding

- Project author **Qalam** is now displayed in the About panel
  (sourced from the new ``/v6/qalam/status`` endpoint).

### 🛠 Verification

- Local Python syntax: validated with ``ast.parse`` on every
  changed ``.py`` file (no syntax errors).
- Render will redeploy automatically on commit to ``main``.
- After deploy, the following URL pattern is expected to return 2xx:
  ``https://laniakea-protocol.onrender.com/v6/qalam/status``
- Smoke test ``smoke_test_v6.py`` continues to pass on the
  v6.0.1-Mainnet base; no test has been deleted or weakened.
